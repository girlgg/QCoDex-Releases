# QCoDex 0.5.2 预览版

本次更新改善 FastFile 目录加载、地图读取和预览交互，并更新原生材质与渲染流程。

## 更新内容

- 批量并行读取 FF24／FF25 资产目录，减少重复查询和写入。启动时复用有效目录及名称索引。
- 补充 FF24 的 XModel、XAnim 和原生配置读取，修复部分 FF25 地形、流分块、静态物件摆放、名称及引用。
- 修复 FF25 地图预览因同键贴图而无法打开的问题。预览显示实际阶段与进度，整图失败时底栏显示失败状态。
- 采用原生程序和来源准备材质。模型、材质和贴图使用同级预览标签页，材质可切换原网格、球与平面。
- 提供前向、延迟和路径追踪三种渲染模式。路径追踪默认使用 OIDN，设置中可选 OptiX，实际可用性取决于显卡和驱动。
- 修复按住右键旋转视角和近距离裁剪。高清贴图补齐采用暂存和完成后发布，合并同一轮补图的通知。

## 升级

退出旧版并备份完整程序目录，尤其是 `data/` 和 `config/`。将 0.5.2 完整解压到新的可写目录，再选择游戏安装和设置偏好。旧库、配置与工程的跨版本兼容性本次未验证，请保留独立备份。

## 运行要求与已知限制

需要 Windows 11 x64、Vulkan 1.3 及支持产品所需功能的显卡驱动。OIDN 的 AMD 和 Intel GPU 后端需要相应的系统驱动。双击 `QCoDex.exe` 打开桌面，命令行用法见 `QCoDex-Cmd.exe --help`。自动补齐高清贴图由设置控制。

大型地图首次预览可能需要数分钟。部分原生材质和场景输入仍待支持，可绘制的几何会用诊断材质呈现缺口。动画 FBX／glTF 导出仍需要完整有效的骨架绑定。程序包提供运行库及第三方通告，游戏资产和词库由用户自行选择。
