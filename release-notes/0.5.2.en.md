# QCoDex 0.5.2 Preview

This release improves FastFile catalog loading, map reads and preview controls. It also updates native material preparation and rendering.

## Changes

- Read FF24 and FF25 catalogs in parallel batches, with fewer repeated queries and writes. Reuse valid catalog and name indexes at startup.
- Expand FF24 XModel, XAnim and native configuration reading. Fix selected FF25 terrain, streamed sections, static placements, names and references.
- Fix FF25 map previews that failed on duplicate texture keys. Previews show the current stage and measured progress. The status bar identifies failed previews.
- Prepare materials from native programs and source bindings. Model, material and texture previews use peer tabs. Material previews can switch between the source mesh, a sphere and a plane.
- Provide forward, deferred and path-traced rendering. Path tracing defaults to OIDN and exposes OptiX in settings, subject to GPU and driver support.
- Fix right-button camera rotation and close-range clipping. Stage high-resolution texture downloads before publishing them and show one notification per update.

## Upgrading

Close the old version and back up its full folder, especially `data/` and `config/`. Extract 0.5.2 into a new writable folder, then select the game installation and configure preferences. Keep separate backups of earlier data and documents. Cross-version compatibility was outside this release check.

## Requirements and known limitations

Windows 11 x64 and a Vulkan 1.3-capable GPU and driver with the required features. The AMD and Intel GPU backends for OIDN require their corresponding system drivers. Run `QCoDex.exe` for the workbench or `QCoDex-Cmd.exe --help` for the CLI. Settings control automatic high-resolution texture downloads.

Large maps may take several minutes to show the first frame. Some native materials and scene inputs remain unsupported. Available geometry uses diagnostic materials where appropriate. Animation FBX/glTF export still requires a complete, valid skeleton binding. The package includes runtimes and notices. Select your own game installation and optional name dictionary.
