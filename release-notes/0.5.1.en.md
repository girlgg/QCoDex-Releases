# QCoDex 0.5.1 Preview

This update improves asset loading, names and search, and fixes selected model, material and map source bindings. QCoDex remains a public preview; available operations depend on the source format and complete required inputs.

## Changes

- Improve FastFile input reuse, block reads, batched catalog writes and name loading, reducing repeated reads and list refreshes.
- Fix matching totals in paginated queries, add Boolean search expressions and improve broad substring searches.
- Make name dictionaries optional and refresh displayed names after updates. Fix bilingual bindings, localized string decoding and selected composition name inconsistencies.
- Improve loading progress and notifications, showing text progress below loading content and reducing duplicate task notifications.
- Fix selected FF24/FF25 native layouts, metadata-only patches, shared streamed images and dependency-source reads.
- Fix character, weapon and model-material source bindings, plus selected map World layouts and preview failure reporting.
- Add download proxy settings, GitHub connection diagnostics and restoration of the previously selected source at startup. Network operations still require explicit permission for the relevant action.
- Reorganize shared preview, export, rendering and background workflows, and improve error and crash diagnostics.

## Upgrading

Close the previous version and back up its complete application folder, especially `data/` and any `config/` directory. Extract 0.5.1 into a new writable folder, then select your game installation and configure dictionaries and preferences again.

This version does not migrate old settings, installation registrations, dictionaries or catalogs. Do not overwrite the new version with the old `data/` or `config/` directory. Configuration now lives in `config/` beside the executables; the business database, caches and user documents default to `data/`. Keep independent backups of old user projects; cross-version project compatibility has not been verified for this release.

## Requirements and limitations

Windows 11 x64 with a GPU/driver supporting Vulkan 1.3 and the required device features. Qt, the VC++ runtime and application dependencies are bundled. Run `QCoDex.exe` for the desktop or `QCoDex-Cmd.exe --help` for CLI usage.

Game assets, dictionaries and private configuration are not included. Language labels on audio names do not guarantee the spoken language. Unknown source formats may remain unsupported. Animation FBX/glTF exports still require complete, valid skeleton bindings.

Third-party information follows the current build: add Glaze, OpenCV (including libpng/zlib and related notices), Tracy, LZ4 and VulkanMemoryAllocator; remove obsolete nlohmann/json and toml++ entries, and restore FLAC license deployment. Full terms are in `licenses/` and `THIRD-PARTY-NOTICES.md`.
