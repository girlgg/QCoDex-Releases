# QCoDex 0.5.1 预览版

发布前审阅稿，尚未发布。

本次更新重点改善资源加载、名称与搜索，并修复部分模型、材质和地图来源绑定。仍为公开预览版，实际能力取决于来源格式和所需数据是否完整。

## 更新内容

- 优化 FastFile 输入复用、分块读取、目录批量写入及名称加载，减少重复读取和列表刷新。
- 修复分页匹配数量统计，支持布尔搜索表达式，并改善宽泛子串搜索。
- 词库改为可选输入；更新名称后自动刷新显示。修复双语名称绑定、本地化字符串解码和部分组装名称一致性问题。
- 改善加载进度与通知显示；内容加载时在内容下方显示文字进度，减少重复任务通知。
- 修复部分 FF24／FF25 原生结构、元数据补丁、共享流图像和依赖来源读取。
- 修复角色、武器和模型材质来源绑定，以及部分地图 World 布局与预览失败反馈。
- 增加下载代理设置、GitHub 连接诊断和启动时的历史来源恢复。联网仍由具体操作明确允许。
- 整理共享预览、导出、渲染及后台任务流程，完善错误与崩溃诊断。

## 升级须知

退出旧版并备份完整程序目录，尤其是 `data/` 和已有的 `config/`。将 0.5.1 完整解压到新的可写目录，首次运行后重新选择游戏安装、配置词库及偏好设置。

当前版本不迁移旧设置、安装登记、词库和目录库；不要将旧 `data/` 或 `config/` 整体覆盖到新版。新的配置位于 EXE 同级 `config/`，业务数据库、缓存和用户文档默认位于 `data/`。保留旧用户工程的独立备份；本次未验证旧工程跨版本兼容性。

## 运行要求与限制

Windows 11 x64，支持 Vulkan 1.3 及所需功能的显卡和驱动。Qt、VC++ 运行库及程序依赖随包提供。运行 `QCoDex.exe` 打开桌面，命令行使用 `QCoDex-Cmd.exe --help`。

包内不包含游戏资产、词库或私人配置。音频名称的语言标签不保证实际配音语言；未知资源格式仍可能不受支持。动画 FBX／glTF 导出仍需完整有效的骨架绑定。

第三方组件已按当前构建同步：新增 Glaze、OpenCV（含 libpng／zlib 等条款）、Tracy、LZ4、VulkanMemoryAllocator；移除已退出产品的 nlohmann/json 与 toml++ 记录，补齐 FLAC 许可部署。完整条款见包内 `licenses/` 和 `THIRD-PARTY-NOTICES.md`。
